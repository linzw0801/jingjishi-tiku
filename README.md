## 一、iOS 上为什么打不开？（重要）

**点 HTML 文件只有表头、看不到题目，不是文件坏了。**

原因：iOS「文件」App 用的是 **Quick Look 预览器，它禁用了 JavaScript**。刷题页的题目靠 JS 渲染，所以只剩静态表头。

另外 iOS 上**没有「用 Safari 打开」这个选项**，因为：
- 分享菜单里出现的 App，必须在系统里登记「我能处理 .html 文件」。**Safari 只登记了 http/https 网址，不登记本地文件**，所以系统不会把它列出来。
- iOS 的 Safari 也**不允许**在地址栏输入 `file:///...` 打开本地文件。

### 关键：同一个文件，**入口不同，结果不同**

| 打开方式 | 用的渲染器 | 跑 JS？ | 结果 |
|---|---|---|---|
| Minis 里点 `minis://workspace/...` 链接 | Minis 内置网页视图 (WKWebView) | ✅ 跑 | 正常 |
| 微信/文件 App →「用其他应用打开」→ Minis | 系统文档预览器 (QuickLook 类) | ❌ 不跑 | 卡表头 |
| 豆包 / Safari / Chrome 打开 | 完整浏览器内核 | ✅ 跑 | 正常 |

原因：iOS 的「用其他应用打开」是把文件当**文档**交给目标 App，App 普遍用系统 `QLPreviewController` 展示，
该预览器**沙箱化并禁用 JavaScript**。而 Minis 内部链接走的是自己的 WebView，JS 正常执行。

👉 **所以「全兼容版」是唯一一个两边都能用的文件**（见下方文件清单）。

### 结论：iOS 上打开本地 HTML 只有这几条路

| 方式 | 说明 |
|---|---|
| ✅ **发链接（最省事）** | 见下方「在线链接」，点开就是真网页，任何手机任何浏览器都能用 |
| ✅ **静态版文件** | `中级经济师历年真题_静态版.html` 不含 JavaScript，Quick Look 里也能正常看题 |
| ✅ **装个支持 HTML 的 App** | Documents（Readdle）、Alook、Kiwi 等；装完分享菜单里就会出现它们 |
| ✅ **用电脑打开** | 双击即可，Chrome/Edge/Safari 都行 |

## 四、页面功能（交互版）

- 顶部切换 **经济基础 / 人力**，右上角 **错题本** 按钮
- **历年真题 / 全部题目 / 本科目错题** 范围筛选
- **顺序 / 随机**；**按试卷刷**（可单刷某一套卷）
- 提交即判分，选项标红标绿 + 正确答案 + 考点解析
- **错题本**：答错自动收录，答对自动移出，可手动移出、清空、导出 Markdown
- 一轮结束出正确率与错题回顾
- 首页 **「📤 把这个文件分享给别人」** 可调起系统分享面板（仅单文件版显示）

## 六、重新生成与上传

```sh
cd /var/minis/workspace/经济师刷题
python3 build_data.py      # 清洗源数据 -> data-*.js + Markdown（需 /tmp/quiz-*.js 原始题库）
python3 build_single.py    # -> 中级经济师刷题.html
python3 build_lite.py      # -> 中级经济师刷题_真题版.html
python3 build_static.py    # -> 中级经济师历年真题_静态版.html

# 上传拿在线链接（72h 有效）
curl -F "reqtype=fileupload" -F "time=72h" \
  -F "fileToUpload=@中级经济师刷题_真题版.html" \
  https://litterbox.catbox.moe/resources/internals/api.php
```
